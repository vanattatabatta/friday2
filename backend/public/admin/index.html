The whole database (library documents and pages, users, orders, chats, settings) is saved on the server about a minute after anything changes, and once more when the server stops. Use this after a fresh deploy that came up empty, or to go back to an older copy: choose the db-latest.tar.gz you downloaded (or an hourly / daily copy). The current data is saved first as db-before-restore-…, then the site restarts once with the chosen data.

DB Transfer: Neon to Neon

Copies the whole database (tables, documents, pages, users, settings) from the source Neon database into the destination. Rows already in the destination are never changed or deleted. The connection strings are used only while the transfer runs: they are not saved and never shown in the log.

Run one step at a time

"Transfer database now" runs 1, 3 and 4 in order. Run the steps by hand only if you want to stop in between.
